# Catppuccin Mocha file icons

This directory vendors the Catppuccin Icons for VS Code Mocha theme from
[`catppuccin/vscode-icons` v1.26.0](https://github.com/catppuccin/vscode-icons/releases/tag/v1.26.0).

- Source theme: `dist/mocha/theme.json`
- Source assets: `dist/mocha/icons/*.svg`
- License: MIT; see `LICENSE.txt`

The files are bundled with Gander at build time. Gander does not read an
installed VS Code extension or download theme data at runtime.
