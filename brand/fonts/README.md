# Brand font

**Bricolage Grotesque** by Mathieu Triay.

- Wordmark weight: 700 (Bold), letter-spacing -2 at a 92pt drawing size
- License: SIL Open Font License 1.1
- Source: https://github.com/google/fonts/tree/main/ofl/bricolagegrotesque

`BricolageGrotesque.ttf` is the variable font, carrying the optical size, width,
and weight axes. Install it locally before editing any lockup SVG that still
contains live text — Google Fonts `@import` does not resolve in Inkscape.

The shipped lockups in `brand/svg/` have their text converted to paths, so they
render without the font installed.
